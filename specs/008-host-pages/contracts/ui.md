# Contract: صفحه‌های میزبان

این کار API ندارد (`backend/openapi.json` دست نمی‌خورد). قرارداد آن صفحه‌ها و رفتار دیدنی آن‌هاست. ظاهر همان تم کار ۰۰۷ است.

## صفحه‌ها

| مسیر | محتوا | بی نشست |
| --- | --- | --- |
| `/{locale}/host` | آگهی‌های من: کارت هر آگهی (کاور در `arch-soft`، عنوان، شهر، قیمت شبانه، نشان وضعیت و، اگر هست، «عکس‌ها کامل نیست»)، و دکمه‌ی «آگهی تازه». بی آگهی: صفحه‌ی خالی گرم با «ساخت اولین آگهی» | ورود، و بازگشت |
| `/{locale}/host/new?step=1..8` | ساخت گام‌به‌گام: سرآیند «گام n از ۸» با نوار پیشرفت، و پایین «قبلی» و «بعدی» (روی گوشی ثابت پایین، به‌جای نوار پایین). گام ۸: عکس‌ها و «ارسال برای بازبینی» | ورود، و بازگشت |
| `/{locale}/host/listings/[id]?tab=details\|photos\|bookings\|reviews` | سرآیند با کاور، عنوان، وضعیت و کلید فعال یا غیرفعال؛ برای آگهی ردشده، دلیل رد و «ارسال دوباره». زبانه‌ها: مشخصات (همان فیلدهای گام ۱ تا ۷، با هشدار R8)، عکس‌ها، رزروها، نظرها | ورود، و بازگشت. آگهی کس دیگر: «یافت نشد» |

## اجزای تازه

| جزء | کار |
| --- | --- |
| `HostLink` (در `Header`) | «میزبان شوید» یا «آگهی‌های من» (R11) |
| `ListingWizard`، `steps/*` | گام‌ها، پیش‌نویس و بررسی هر گام |
| `LocationPicker` | نقشه با پین قابل‌کشیدن و کادرهای عرض و طول (R6) |
| `MoneyInput` | قیمت با تومان برای ریال، و رقم فارسی (R7) |
| `PhotoManager` | انتخاب، بررسی، پیش‌نمایش، پیشرفت، دوباره، ترتیب (کشیدن و دکمه)، کاور، برچسب و توضیح، حذف با قاعده‌ی ۳ عکس |
| `HostListingCard`، `StatusBadge` | کارت و نشان وضعیت (R10) |
| `ReviewWarningDialog` | هشدار پیش از ذخیره‌ای که آگهی تأییدشده را پنهان می‌کند (R8) |
| `HostBookings` | رزروهای آگهی، پیش‌رو اول، با صفحه‌بندی |

## متن‌های تازه (`messages/{fa,en}.json`، از `scripts/messages_source.py`)

بخش‌های `host.*` (فهرست، کارت، وضعیت، هشدار، رزروها)، `wizard.*` (۸ گام، برچسب‌ها، راهنماها و پیام‌های هر فیلد)، `photos.*` (انتخاب، پیشرفت، دوباره، ترتیب، کاور، برچسب، حذف، قاعده‌ی ۳ عکس)، و `nav.becomeHost` و `nav.myListings`.

**کدهای خطای میزبان:** ترجمه‌ی آن‌ها از کار ۰۰۵ در فایل‌های ترجمه هست، از جمله `invalid_storage_key`، `upload_missing`، `invalid_photo_order` و `listing_not_rejected`. تست `messages.test.ts` این را نگه می‌دارد.
